# UBL 前端网页设计代码｜版本1

本文件夹包含当前可直接运行的 UBL 官网前端代码与全部使用的本地素材。

## 文件说明

- `index.html`：页面结构。
- `styles.css`：页面样式、响应式布局和动画。
- `script.js`：圆形照片画廊、沙滩开关、价格交互、滚动过渡等交互逻辑。
- `assets/`：网页图片和 EgoClip 动画帧素材。

## 本地预览

在本文件夹内启动任意静态 HTTP 服务后，打开 `index.html` 即可预览。例如：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。
