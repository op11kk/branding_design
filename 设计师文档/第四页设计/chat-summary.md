# Eagle Clip 网页设计聊天总结

## 1. 项目背景

- 产品：Eagle Clip（产品介绍 PDF 中也出现过 `EgoClip` 命名，需要后续统一品牌名称）。
- 产品类型：面向具身智能 / Physical AI 的消费级真实世界数据采集设备。
- 佩戴位置：衣领下方、胸口正中间。
- 核心功能：通过可穿戴小摄像头采集人类日常生活视频数据，经过 AI 筛选、数据贡献和处理后，为机器人训练大模型提供真实世界行为数据。
- 产品价值：低门槛、低摩擦、可穿戴、可规模化，让普通人的日常生活转化为真实世界数据价值和潜在收入。

## 3. 第一版网页方向

用户提供了一个棕色背景、中心文案、周围分布生活照片的草稿，并提出：

- 首屏先只展示两行主文案。
- 页面向下滚动时，生活照片从中心一点向外发散。
- 背景可以使用动态视频、轻微运动的风景或其他动态效果。
- 页面需要突出科技感、可信度、低门槛和大众可参与性。

第一版实现采用：

- 纯 HTML / CSS / JavaScript 单页。
- 使用 `position: sticky` 制作滚动叙事场景。
- 使用滚动进度控制照片从中心向外展开。
- 使用晨雾草地背景、缓慢光影、颗粒和轻微视差代替视频，降低加载成本。
- 使用生活场景照片组成 4×2 图片素材网格，再通过 CSS 背景位置切出 8 张照片。

## 4. 后续视觉修改要求

用户随后提出了以下修改：

1. 所有照片必须摆正，不能有倾斜或旋转角度。
2. 主标题改为方正、粗重、几何感的字体，不要花体。
3. 展开照片取消外侧白色边框。
4. 照片不必组成规整圆形，可以自由分布，大小不一。
5. 背景不要偏绿色阴沉，需要更暖、更有朝气，可使用黄色、绿色或翠绿色。

已完成的对应修改：

- 使用 `Archivo Black` 替代衬线花体。
- 所有照片旋转角度设为 0。
- 移除照片白色边框。
- 重新设置照片位置与尺寸，形成不规则分布。
- 背景改为明亮晨光、黄色高光和翠绿色草地。
- 手机端额外调整右侧照片位置，避免遮挡主标题。
