# 8.14 聊天记录 v1

> 项目：Universal Basic Layer（UBL）官网交互设计与前端实现
>
> 记录范围：本次对话中确认的视觉方向、页面结构、交互规则、修改历史与当前实现状态。

## 1. 项目目标

为 UBL 官网制作一组连续的沉浸式页面，围绕“日常生活被记录、被赋予价值、并回到用户手中”的叙事展开。页面采用大尺寸主体图、全屏滚动、真实照片与轻量交互结合的方式呈现。

页面顺序为：

1. UBL 静态开屏页。
2. 生长过渡页。
3. 第一人称生活照片圆形画廊页。
4. 沙滩记录与价值展示页。
5. Waitlist 招募页。

## 2. 第一页：UBL 静态开屏

### 最终确认

- 主视觉使用用户提供的草地人物与左上角光束素材，裁切为 4:3 视觉比例后作为整页主体。
- 不需要其他正文文案，开屏仅显示 `UBL`。
- 页面整体不做强烈运动。
- 左上角光束保留轻微动态：可有细微左右摆动与明暗呼吸，不能影响静态、安静的氛围。

### 已实现方向

- 使用 `assets/ubl-still-hero-4x3.png`。
- 以全屏静态主图呈现，叠加低强度灯光动态。

## 3. 第二页：生长过渡叙事

### 叙事要求

- 作为第一页进入生活照片页前的过渡。
- 表现从一滴水、根系、幼苗到树木/世界生成的过程。
- 用户下滑时画面上下推进，不采用左右翻页。

### 当前实现方向

- 页面包含水滴落下、涟漪、根系、生长枝叶和完整背景树的滚动进度动画。
- 使用柔和的蓝紫、粉橘与土壤色，作为 UBL 开屏与生活记录之间的过渡。

## 4. 第三页：第一人称生活照片圆形画廊

### 素材与基础规则

- 使用八张第一人称生活照片：UNO、喂鸽子、打包行李、牵手、洗衣房、听音乐、骑行、喂海鸥。
- 八张照片全部保持 `4:3` 比例，不改为竖图或其他比例。
- 背景为浅蓝偏绿色的水感纹理，避免此前过深的蓝色。
- 不要在画廊中央放置文案。
- 第三页必须是正常的完整网页高度，撑满视口，不能显得比其他页面小。

### 最终布局与运动要求

- 画廊只修改第三页的照片区域，其他页面与第三页背景不随此次调整改变。
- 照片摆放参考用户提供的 Circle Gallery 截图：多张正向卡片沿画面中心的圆形路径紧密重叠、形成一组卡片堆叠。
- 不是横向 Coverflow，也不是带大空洞的平面圆环。
- 照片在圆形轨迹上顺时针旋转。
- 卡片保持正向，不随轨迹自身倾斜；通过前后层级、缩放和叠放来表现圆形顺序。
- 中间不能出现明显大空隙。
- 照片需要比最早版本更小，避免被画面边缘裁切。

### 交互要求

- 支持鼠标或触屏横向拖拽。
- 拖拽松开后保留惯性。
- 点击一张可见照片后，该照片平滑移动至画面中心并保持停留。
- 卡片需要具备可访问的按钮语义与键盘切换能力。

### React Bits 参考

- 用户参考 React Bits Pro 的 Circle Gallery：`@reactbits-starter/circle-gallery-tw`。
- 当前项目为静态 HTML/CSS/JS，未配置 React、shadcn、`components.json` 或 `REACTBITS_LICENSE_KEY`，因此当前以原生方式实现相同的交互逻辑，不复制受授权保护的组件源码。

### 当前实现状态

- 已完成浅青绿色 4:3 水感背景。
- 已完成八张图片的紧密圆形叠放与顺时针自动旋转。
- 已完成拖拽惯性与点击照片居中。
- 已检查桌面和移动尺寸；卡片维持 4:3。

## 5. 第四页：沙滩记录与价值回流

### 沙滩主页面

- 初始主图使用扩大版、灰色开关、无价格的沙滩图片，进入页面时应填满整张网页，不留白。
- 沙滩画面可以拖动浏览，参考 Draggable Grid 的可拖动背景体验。
- `allow to record` 文字及开关放大约四倍。
- 开关初始为灰色关闭状态；点击后按苹果式 Switch 动画转为绿色开启状态。
- 关闭时人物头顶价格和连接线均不显示。
- 开启后才显示每个人头上的价格与连接线。

### 价格与连线

- 人物头顶价格可点击。
- 点击某个人的价格，右侧 EgoClip 手机页面显示对应金额。
- 连线参考地图路径上的跳动效果：仅保留线上的流动/跳点，不显示地图本身。

### 滚动切换与左右分屏

- 下滑时，沙滩画面从主图状态转入左右 50/50 的分屏。
- 左侧完整保留 16:9 沙滩画面，不允许裁切破坏比例。
- 右侧为完整居中的 EgoClip 手机，不允许只露出半个手机。
- 画面与 Waitlist 页面之间采用上下翻页感的过渡，不使用左右翻动。

### EgoClip

- 右侧使用 EgoClip 手机画面。
- Ego Clip 产品图允许横向拖动约 30–40 度。
- 手机中显示与所选沙滩人物对应的金额。

## 6. 第五页：Waitlist 招募页

### 主视觉与背景

- 使用人物与漂浮 Waitlist 框的主图作为基础。
- 背景环境希望增加绿植，海更蓝，整体更自然。
- 人物保持不动。

### 白色/绿色 Waitlist 卡片

- 多个 Waitlist 卡片围绕人物旋转。
- 旋转速度先提高 20%，后又提高 10%。
- 移除不喜欢的白色椭圆形运动轨迹线。
- 卡片尺寸需要适当放大。
- `Join waitlist`、`Notify me`、`Sign up` 等可点击入口改为与植物呼应的绿色。
- 点击入口进入填写用户信息的页面。

### 人物遮挡规则

- 当卡片转到人物身前时，可以覆盖在衣服前方。
- 当卡片运动至头部后方时，必须被头部遮盖；从头部左边再次转出。
- 需要维持人物不动、卡片运动的效果。
