# UBL 官网设计方案 PRD

## 项目目标

为 Universal Basic Layer（UBL）制作一组连续、沉浸式的官网页面：让「日常生活被记录、被赋予价值、并回到用户手中」成为一条可感知的视觉叙事。页面以真实影像、全屏滚动和轻量交互为主，而不是静态展示页。

主线：**手与水 → 水滴与种子 → 大树与 UBL → 蓝色入口 → 生活片段 → 沙滩与收入 → Waitlist**。

## 页面与功能范围

| 优先级 | 页面/功能 | 用户任务 | 验收标准 |
| --- | --- | --- | --- |
| P0 | 手与水开场 | 进入并理解 UBL 的情绪基调 | 轻柔视频感开场，中央仅保留 UBL 标题；水与小花具有低强度流动感 |
| P0 | 水滴到大树 | 随滚动理解记录如何生成价值 | 水滴、涟漪、土壤、种子和大树构成连续因果转场 |
| P0 | 蓝色入口与生活画廊 | 浏览生活片段 | 从树冠蓝色区域进入整页蓝色；图片采用可旋转、可拖拽、可聚焦的 Circle Gallery |
| P0 | 沙滩与收入 | 打开记录并查看对应收益 | Allow to Record 开关触发金额/连线；场景进入左右 50/50 的沙滩与手机布局 |
| P0 | Waitlist | 提交报名意向 | 柔和 Soft UI 表单和清晰 CTA；可从沙滩连线汇聚的箭头过渡进入 |

## 页面需求

### 1. 开场：手与水

- 动作顺序：手在水里 → 整只手抬出水面 → 捧起一捧水。
- 标题可使用 `UBL` 或 `UBL (Universal Basic Layer)`；副标题只预留容器，暂不锁定文案。
- 视觉节奏缓慢、湿润、近距离；不做快速切镜。

### 2. 水滴 → 种子 → 大树

- 从手中抽离一滴重点水珠，向下坠落。
- 水珠落水形成中心涟漪，镜头继续下潜进入土壤。
- 水流触发种子发芽、生长，最终形成一棵冲天大树。

### 3. 大树、蓝色入口与生活片段

- 上半屏为「树冠形成蓝色 UBL」的画面；下半屏为完整 4:3 纯蓝色页面。
- 滚动要有从树冠蓝色区域钻入纯蓝空间的连续感；纯蓝屏可直接用 CSS 实色实现。
- 生活图片采用 Circle Gallery：圆形/环形路径、顺时针旋转、拖拽惯性、点击居中，并保持键盘可访问性。

### 4. 预留页

- 原先的蓝色长出双手、第一视角闪现、鸡蛋花 wave、进入产品等内容尚未最终确认。
- 本版本只预留位置，不提前实现。

### 5. 沙滩、Allow to Record 与手机

- 初始是可拖拽浏览的完整沙滩场景；开关初始关闭，人物金额与连线不可见。
- 开启后显示金额和连接线；点击金额，右侧 EgoClip 手机展示对应金额。
- 向下进入左右 50/50 布局：左侧完整保留 16:9 沙滩，右侧完整居中手机；人物连线最终汇聚为指向 Waitlist 的箭头。

### 6. Waitlist

- 作为叙事收口，方向为柔和阴影、米白背景、圆角输入框和绿色 CTA 的 Soft UI。
- 建议文案：`让你的生活进入 UBL。记录真实世界的时刻，让价值回流给创造它的人。`
