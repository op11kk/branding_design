# Harmone Web

一个由两人协作完成的前端页面设计项目。

## 协作分工

| 角色 | 主要负责 | 交付物 |
| --- | --- | --- |
| 设计负责人 | 需求澄清、PRD、信息架构、页面/组件规范、验收标准 | `docs/PRD.md`、`docs/design/` |
| 前端负责人 | 技术选型、页面实现、组件开发、联调与质量保障 | `docs/engineering/`、`src/`（建立后） |

## 文档入口

- [协作流程与交接规范](docs/COLLABORATION.md)
- [产品需求文档（PRD）](docs/PRD.md)
- [设计规范与交付清单](docs/design/DESIGN_SPEC.md)
- [前端实现计划](docs/engineering/IMPLEMENTATION_PLAN.md)

## 推荐协作节奏

1. 设计负责人先补全 PRD 的目标、用户、页面范围与验收标准。
2. 设计负责人在设计规范中登记每个页面、组件状态和设计稿链接。
3. 前端负责人按实现计划拆分任务，开发时同步状态与阻塞项。
4. 每个页面按 PRD 验收标准共同验收，再合并到主分支。

> 文档中的“待填写”项是项目启动时需要两人共同确认的内容。
