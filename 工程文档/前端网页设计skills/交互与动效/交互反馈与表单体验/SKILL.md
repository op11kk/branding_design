# 交互反馈与表单体验

## 工作流

1. 列出用户操作、系统响应、等待、成功、失败和可撤销路径。
2. 对即时操作给出 pressed 或状态变化；对异步操作给出进度、loading 与重复提交保护。
3. 失败信息说明原因、影响和下一步，不以模糊的“失败了”结束。
4. 保留用户已经输入的内容；危险操作要求确认或提供撤销。
5. 用键盘、触摸和慢网络分别走一遍完整流程。

## 验收

- 每次操作在合理时间内都有可见反馈；
- 用户不会因网络或校验错误丢失输入；
- 同一动作不会被重复提交。
