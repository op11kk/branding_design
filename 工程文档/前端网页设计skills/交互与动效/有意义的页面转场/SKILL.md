# 有意义的页面转场

## 何时使用

列表到详情、卡片到弹窗、内容异步到达、列表重排或有明确前进/后退语义的导航。

## 工作流

1. 先写清动效表达的关系：同一对象、内容到达、排序变化或层级导航；没有关系就不用动效。
2. 列表到详情优先用共享元素；数据到达使用轻量 enter/exit；标签切换通常用淡入淡出而非方向滑动。
3. React 中仅在 `startTransition`、`Suspense` 或合适的延迟值机制内触发 View Transition。
4. 不支持的浏览器必须自然退化为无动画，不影响操作与阅读。
5. 避免只为装饰而给每个元素添加弹跳、旋转或连续循环。

## 验收

- 用户能解释该动效传达的关系；
- 转场不阻塞输入、滚动和返回；
- 前进、后退、刷新与无动画降级均可用。
