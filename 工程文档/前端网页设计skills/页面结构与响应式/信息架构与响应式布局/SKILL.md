# 信息架构与响应式布局

## 工作流

1. 先排定用户任务和信息优先级，再决定页面区块与导航层级。
2. 以内容失效点而非设备名称定义断点；记录每个断点发生的布局、密度和交互变化。
3. 采用流式宽度、最小/最大尺寸与弹性网格，避免为单一屏幕写死像素。
4. 移动端优先保留核心任务；隐藏或折叠次要内容时提供可发现入口。
5. 检查超宽屏、窄屏、横屏、放大字体和长内容。

## 验收

- 各断点的内容优先级一致；
- 没有横向滚动、重叠或不可点击控件；
- 导航与主操作在手机上仍易发现。
