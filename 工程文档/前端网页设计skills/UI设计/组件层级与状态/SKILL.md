# 组件层级与状态

## 何时使用

设计表单、卡片、导航、数据列表、弹窗或任何需要反复复用的组件时使用。

## 工作流

1. 标记主操作、次操作、辅助信息与破坏性操作，避免所有按钮同等抢眼。
2. 为每个交互组件定义默认、hover、focus、pressed、disabled、loading、error 与 empty 状态。
3. 用尺寸、字重、对比度和留白建立层级，不能只靠颜色。
4. 让触控目标至少达到可舒适点击的尺寸；错误信息紧邻对应输入项并说明修复方式。
5. 用真实的长文本、零数据和失败状态做组件验证。

## 验收

- 用户能在三秒内识别下一步主操作；
- 每个状态都有可见且可键盘访问的反馈；
- 空状态和错误状态不造成页面崩塌。
