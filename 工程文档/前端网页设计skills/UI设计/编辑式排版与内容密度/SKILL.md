# 编辑式排版与内容密度

## 工作流

1. 为标题、导语、正文、注释与数据建立明确的字号、行高和最大行宽。
2. 在密集信息区使用分组、节奏和可扫描的小标题，而非不断加边框。
3. 让图文关系、留白和对齐有意打破或遵守网格；选择一种，并保持一致。
4. 在中文、英文、数字、超长 URL 和移动端上分别检查换行。

## 验收

- 正文连续阅读不疲劳，重要信息可快速扫描；
- 标题层级不跳级；
- 任意语言或长内容不会溢出、遮挡或制造孤行。
