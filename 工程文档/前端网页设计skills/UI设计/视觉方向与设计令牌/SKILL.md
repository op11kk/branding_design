# 视觉方向与设计令牌

## 何时使用

新建品牌页、活动页、产品页，或现有界面缺少统一视觉语言时使用。

## 工作流

1. 明确受众、页面目标与一个可用一句话说清的视觉方向，例如编辑感、工业感、玩具感或克制极简。
2. 建立 CSS 变量：主/辅/强调/语义色，字号比例，字重，圆角，阴影，间距与层级。
3. 选择有性格的展示字体和易读的正文字体；避免把默认系统字体或千篇一律的渐变当作设计结论。
4. 让色彩、留白、图形纹理和组件细节共同服务同一方向，而不是平均分配装饰。
5. 在浅色/深色背景、长标题和异常内容下检查令牌是否仍可用。

## 验收

- 不看 Logo 也能从首屏判断产品气质；
- 任意页面只使用定义过的令牌；
- 文本、按钮、卡片和状态色在不同页面保持一致。
