# 前端网页设计 Skills

本目录按能力分为四类。每个子目录中的 `SKILL.md` 都可作为网页设计、实现或评审任务的执行清单。

| 分类 | Skills |
| --- | --- |
| UI设计 | 视觉方向与设计令牌、组件层级与状态、编辑式排版 |
| 交互与动效 | 交互反馈、页面与共享元素转场、低动效降级 |
| 可访问性与性能 | 可访问性审计、资源与渲染性能、React/Next 性能 |
| 页面结构与响应式 | 信息架构与响应式布局、可组合组件 API |

使用原则：先选择与任务匹配的 Skill，再在设计稿、代码和真实设备上验证；动效、性能和可访问性不能只凭视觉判断。
