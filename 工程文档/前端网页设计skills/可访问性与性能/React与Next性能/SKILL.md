# React 与 Next 性能

## 工作流

1. 将独立请求并行化；先做廉价条件判断，再启动需要的异步操作。
2. 直接导入所需模块；将重组件、图表或编辑器按功能动态加载。
3. 减少从服务端传到客户端的数据与重复序列化；对可复用请求进行去重或缓存。
4. 不在组件内部定义子组件；把昂贵计算放进合适的 memo 或服务端。
5. 将非紧急状态更新放入 transition，保持输入即时响应。

## 验收

- 网络瀑布和重复请求有明确理由或已消除；
- 关键路径 bundle 不包含未使用的大依赖；
- 输入、筛选和滚动时没有明显卡顿。
