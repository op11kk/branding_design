# 可访问性审计

## 工作流

1. 仅使用键盘完成导航、打开弹窗、提交表单和关闭浮层；焦点顺序必须与视觉顺序一致。
2. 使用原生语义元素；只有必要时补充 ARIA，并提供元素名称、角色和状态。
3. 所有可操作元素必须有可见 focus 样式；模态框需锁定焦点并在关闭时返回触发点。
4. 检查文字、图标、状态色与背景的对比度；不能仅用颜色传递错误或选中状态。
5. 给图片、视频和动态内容提供恰当的替代文本、字幕或状态播报。

## 验收

- 不使用鼠标仍可完成核心任务；
- 读屏名称与屏幕可见标签一致；
- 200% 缩放与窄屏下不丢失功能。
