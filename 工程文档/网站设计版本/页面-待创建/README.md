# 页面版本模板

## 已交付版本

- `版本1/`：EgoClip 第一版叙事网页原型。
- `版本2/`：2026-08-17 完整交付版；加入受 3D 工程约束的产品视觉、五种外壳、授权写实素材、本地视频、隐私原则、App 概念、真实/预览表单边界及桌面与手机验收截图。

为每个网页创建一个同级目录，例如 `首页/`、`产品页/`；再按版本创建文件：`v0.1.md`、`v0.2.md`。
