# EgoClip narrative landing page

一版依据 `V2设计方案.html` 实现的响应式单页官网。页面将设计文档中的 8 段叙事做成可运行原型：钱包抽卡、产品卡展开、POV 横向叙事、生活地图、概念社区、外壳切换、App 原型与 waitlist 表单。

## 本地预览

```bash
npm run dev
```

打开 `http://127.0.0.1:4173`。

## 验证

```bash
npm run check
npm test
```

## 素材状态

当前使用 `reference/prd-assets/` 中已有的生活影像作为首版占位。方案中提到但未随附件提供的家庭玄关、正式钱包、6–8 段 POV、穿戴摄影和黄昏街区图，后续可按现有 HTML 图片槽位直接替换。App 中未写入未经商业确认的收益数字。
